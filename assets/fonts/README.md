# Fonts

Generated by `cargo xtask vendor-fonts` (`crates/xtask/src/fonts.rs`): do not edit.

The TTFs are the `files/*-wght-normal.woff2` files of `@fontsource-variable/overpass` 5.3.0 and `@fontsource-variable/overpass-mono` 5.3.0, decoded with `wuff`.
They are variable fonts with a `wght` axis: Overpass 100 to 900 (default 400),
Overpass Mono 300 to 700 (default 300).
Subsets, in fallback order: latin, latin-ext, cyrillic, cyrillic-ext, vietnamese.
